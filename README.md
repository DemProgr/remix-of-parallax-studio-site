# Remix of Parallax Studio Site

# Role

You are acting as a **senior design engineer and visual auditor**.

You are reviewing a portfolio website **generated by Lovable**.  
Your task is **not to redesign from scratch**, but to **analyze, critique, and correct** the existing output until it matches the **structure, hierarchy, rhythm, and visual quality** of the provided references.

The final result must feel like a **high-end, execution-led, premium freelancer portfolio**, strongly inspired by **editorial studios such as Wolff Olins** and **authorial portfolios like Marco Coppeto’s**.

---

# Primary Objective

Refine the current Lovable output so that it:

- Closely **matches the visual and structural system** of the reference sites
- Achieves **near pixel-perfect fidelity** in layout, spacing, and hierarchy
- Removes any trace of “generic template” behavior
- Feels **human, direct, confident, and craft-driven**
- Clearly represents a **generalist designer portfolio**, not an agency website

---

# Site Scope (Mandatory)

The site must contain **exactly** the following pages:

1. **Home**
   - Editorial hero section
   - Project grid
   - Footer
2. **Project Detail** (single reusable template)
3. **About**
4. **Contact**

Total: **6 projects**

---

# Non-Negotiable Design Principles

## 1. Typography

- Use a **strong editorial serif** for headlines (Wolff Olins–style influence)
- Use a **neutral, highly legible sans-serif** for body copy
- Headlines must be:
  - Large
  - Confident
  - Manually broken into lines
  - Generous line-height
- Avoid:
  - Startup / SaaS typography
  - Overly clean or “techy” type systems

If the Lovable output uses generic fonts or timid scales, **replace and rescale**.

---

## 2. Layout & Grid

- Wide editorial grid with **intentional white space**
- White space is part of the design, not empty filler
- Strict alignment rules
- Asymmetry is allowed, randomness is not
- Frequent use of:
  - Thin horizontal rules
  - Editorial section breaks
  - Multi-column text layouts

If anything feels tight, compact, or “efficient”, it is wrong.

---

## 3. Navigation Bar

- Keep the **floating pill-shaped navbar**
- Must match the reference behavior exactly:
  - Rounded pill container
  - Solid background
  - Subtle contrast or shadow
  - Floating above content
  - Persistent on scroll
- Navigation items:
  - Work
  - About
  - Contact

No full-width traditional navbar.  
If simplified by Lovable, **rebuild it properly**.

---

## 4. Home — Hero Section

- Short, human, direct editorial headline
- Confident but not marketing-driven
- Structure:
  - Large headline (left or dominant)
  - Short supporting paragraph (secondary column or offset)
- Solid background (black or white)
- No obvious primary CTA
- No buttons competing for attention

---

## 5. Projects Grid (Home)

- Grid structure inspired directly by the reference site
- Large visual cards
- Image-first hierarchy
- Discreet titles and metadata
- Subtle hover behavior only (fade, underline, micro-shift)

Each project must include:
- Project name
- One-line context
- Role / discipline tags (e.g. Product, Brand, Strategy, Visual)

No flashy animations. No carousels.

---

## 6. Project Detail Page

Mandatory structure:

1. Strong visual hero (image or video)
2. Context block:
   - Project name
   - Year
   - Role
   - Type of work
3. Long-form editorial text
   - Wide reading column
   - Comfortable rhythm
4. Large images
   - Full-width or wide column layouts
5. No corporate case-study patterns:
   - No numbered steps
   - No process diagrams
   - No framework graphics

This should read like an **editorial story**, not a pitch deck.

---

## 7. About Page

- Editorial, magazine-like layout
- Large serif headline
- Long first-person narrative text
- Secondary column with:
  - Experience
  - Awards
  - Talks
  - Clients
- No timelines
